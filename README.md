# LOVORA 💜 — Phase 1 Landing Page

Premium cosmic-marriage-themed landing page, written in Next.js, TypeScript and Tailwind CSS (with custom visual CSS).

## Run

```bash
npm install
npm run dev
```

## Built

- Responsive celestial hero with original animated CSS/SVG orbit art
- English / Hindi content toggle
- Interactive sample reading (3 categories)
- Three benefit cards, 3-step explanation, seven-chapter showcase, ₹299 offer, FAQ
- Smooth reveal transitions respecting reduced-motion settings
- No stock images, generative image API or recurring design cost

## Important: Landing page only

Buttons intentionally scroll to the **illustrative sample** for now. These must point to the birth-details flow after that screen is implemented. Astrology API, payments, report generation, accountless recovery, policies and legal pages are **not yet connected**. The sample is clearly marked and does not impersonate a generated reading. Do not publish this as an operational paid astrology service yet.

npm run typecheck
